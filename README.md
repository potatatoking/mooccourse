# 课程助手

适用于 Chrome／Edge 120+，支持中国大学 MOOC（icourse163.org）网页版。

## 安装和使用

1. 打开 `chrome://extensions` 或 `edge://extensions`，打开「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目里的 `extension` 文件夹。已安装旧版时点击重新加载扩展，再刷新课程页。
3. **视频**。支持 0.25×–16×。默认自动选择面积最大的可见播放器，也可手动切换。自动开始、本节下一段续播和「播完自动播放下一集」可分别开启。开启自动下一集后，主视频正常结束时，扩展会尝试点击可识别的下一集入口并播放新视频。若浏览器拦截自动播放，请在页面点一次播放。
4. **API**。填写完整的 HTTPS 接口地址、模型名和可选密钥。兼容 Chat Completions，本机地址可使用 HTTP。浏览器仅在保存时请求对应 API 域名的访问权限，密钥保存在浏览器本地。
5. **答题**。进入作业、测验或考试的作答页，点一次「一键填写当前页」。关闭扩展面板后会继续填写，重新打开面板可以查看结果。支持单选、多选、判断及可匹配空数的填空题。MOOC 题干和选项中的受支持图片会以链接形式发送给配置的 API，需使用支持图片输入的模型，例如 `deepseek-flash`。检查结果后手动提交。

扩展会逐题请求并填写当前页上可识别的空白题。遇到 API 限流时，面板会显示等待时间，并自动重试当前题。单题收到无效答案时会跳过并继续；若页面切换、API 连接失败或持续限流，任务会停止并保留此前已填写的答案。

已答题会跳过。简答、编程、连线、不受支持的图片和公式、富文本编辑器以及只接受真实点击的自定义控件需手动处理。本节续播使用同一播放器框架里的后续视频。自动下一集依赖课程页提供可识别的「下一集」「下一节」等入口。

## 验证

无需安装依赖。运行 `npm run lint` 和 `npm test`。

设置 `COURSE_CHROME_BIN` 为本机 Chrome 可执行文件路径后再运行 `npm test`，可用隔离的 Chrome 和本地模拟 API 验证逐题填答、限流重试、iframe、Shadow DOM 和自动下一集。样例测试需要本机的 `openssl`。
